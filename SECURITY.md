# Política de seguridad

Esta aplicación maneja datos personales, cuentas y créditos de asociados. Si encuentra un problema de seguridad, le pedimos que lo reporte **en privado** para poder corregirlo antes de que se conozca.

## Qué reportar por esta vía

- Acceso a datos de otra persona (cuentas, movimientos, beneficiarios, documentos).
- Formas de saltarse el inicio de sesión, la verificación en dos pasos o los permisos de un rol.
- Contraseñas, códigos 2FA, tokens o claves visibles en pantallas, correos, registros o respuestas de la API.
- Mensajes o respuestas que permitan averiguar si una cuenta existe.

Los errores que no tienen que ver con seguridad se reportan como issue normal con el formulario **Reportar un error**.

## Cómo reportarlo

1. Entre a la pestaña **Security** del repositorio y elija **Report a vulnerability** (o use [este enlace](https://github.com/StevOxd/cooperativa-app/security/advisories/new)).
2. Describa:
   - qué encontró y qué permite hacer;
   - los pasos para reproducirlo;
   - la pantalla, el endpoint o el archivo afectado, si lo sabe.
3. **No** lo publique en issues, pull requests ni comentarios mientras no esté corregido.

El reporte solo lo ven los mantenedores del repositorio. Le responderemos en ese mismo espacio para confirmar que lo recibimos y avisarle cuando esté corregido.

## Versiones con soporte

Solo la rama `main` recibe correcciones de seguridad.
